# ランニングイベント手帳（PWA版）

大会ごとの練習計画・当日の段取り・振り返りをまとめる、ブラウザで動くアプリです。
サーバーもアカウントも使いません。記録は、開いた端末のブラウザの中にだけ保存されます。

## ファイル構成
- `index.html` … アプリ本体（HTML・CSS・JSが1ファイルに入っています）
- `manifest.webmanifest` … ホーム画面に追加するための設定（名前・色・アイコン）
- `sw.js` … オフラインで開くための仕組み
- `icons/` … アイコン

## 公開のしかた（GitHub Pages）
1. 新しいリポジトリを作り、このフォルダの中身をすべてルートに置く
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. 表示されたURL（`https://ユーザー名.github.io/リポジトリ名/`）をスマホで開く

※ `https` で配信されている場所でないと、オフライン機能は動きません。

## スマホのホーム画面に追加
- iPhone：**Safari**で開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → メニュー → 「ホーム画面に追加」または「アプリをインストール」

## アプリを更新したとき
`index.html` を差し替え、`sw.js` の `CACHE_VERSION`（例：`running-event-app-v1` → `v2`）を変えてください。
オンラインで開くと最新が読み込まれます（次回起動で反映されることがあります）。

## データについて
- 記録は端末ごとに別々です。端末を変えるときは、設定の「JSONを書き出す／読み込む」で移します。
- ブラウザのデータを消すと記録も消えます。ときどきJSONを書き出しておくと安心です。
- 天気・大会情報の自動取得は、設定でオンにした人だけが使えます（初期はオフ・通信なし）。
